# 取調室のジレンマ（授業用・一回限りの囚人のジレンマ）

いろいろな「相棒」（こわそうなヤクザ／優しそうな女性／宇宙人／かわいいロボット／柴犬／無機的なコンピュータ／子ども）と、
1人ずつ一度きりの囚人のジレンマを行う 3D ゲームです。PC・スマホどちらでも動きます。
学生の選択は Google スプレッドシートに自動で集まり、先生用画面で相手別の協力率を見たり CSV をダウンロードしたりできます。

```
index.html      … 学生が遊ぶページ
admin.html      … 先生用ダッシュボード（協力率グラフ・CSV・参加者名簿）
config.js       … 設定（送信先URLなど）← ここだけ書き換える
js/             … ゲーム本体
lib/three.min.js… 3D描画ライブラリ（同梱）
gas/Code.gs     … Google Apps Script（ログ受け取り用）
```

## 準備（初回だけ・15分ほど）

### 1. ログを受け取るスプレッドシートを用意する

1. Google ドライブで **新しいスプレッドシート** を作る（名前は自由。例：「囚人のジレンマ ログ」）
2. メニューの **拡張機能 → Apps Script** を開く
3. 最初からある `コード.gs` の中身を全部消して、`gas/Code.gs` の中身を丸ごと貼り付ける
4. 先頭の `ADMIN_KEY = '...'` を好きな合言葉に変えて保存（💾）
5. 右上の **デプロイ → 新しいデプロイ**
   - 歯車 ⚙ → 種類：**ウェブアプリ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
     （大学の Google Workspace アカウントだと「組織内の全員」しか選べないことがあります。その場合、学生が大学アカウントでログインしていないと送信に失敗するので、個人の Google アカウントで作るのが確実です）
6. 「アクセスを承認」→ アカウントを選ぶ →「このアプリは Google で確認されていません」と出たら **詳細 → （プロジェクト名）に移動** → 許可
7. 表示される **ウェブアプリ URL**（`https://script.google.com/macros/s/……/exec`）をコピー

### 2. config.js に URL を貼る

```js
GAS_URL: 'https://script.google.com/macros/s/……/exec',
```

### 3. GitHub Pages で公開する

1. GitHub で新しいリポジトリを作る（例：`pd-game`、**Public**）
2. リポジトリのページで **Add file → Upload files** を選び、このフォルダの中身（`index.html`, `admin.html`, `config.js`, `js/`, `lib/`, `gas/`, `README.md`）をまとめてドラッグ＆ドロップ → Commit
3. **Settings → Pages** →「Build and deployment」の Source を **Deploy from a branch**、Branch を **main / (root)** にして Save
4. 1〜2分で次のURLで公開されます
   - 学生用：`https://<ユーザー名>.github.io/pd-game/`
   - 先生用：`https://<ユーザー名>.github.io/pd-game/admin.html`

学生用URLは QR コードにしてスライドに貼ると、スマホからすぐ入れます。

### 4. 動作確認

1. 学生用ページを開き、学籍番号に **TEST** と入れて最後まで遊ぶ
2. 「送信完了」と出たら、スプレッドシートの `log` シートに7行増えていることを確認
3. 先生用ページで URL と合言葉を入れて「読み込む」
   （TEST で始まる学籍番号は、初期設定で集計から除外されます）

ダミーデータで画面だけ確認したいときは `admin.html?demo=1` を開いてください。

## 授業での流れ（例）

1. 学生用URL（QR）を配る → 各自が学籍番号を入れて開始（5〜8分）
2. 先生用画面で「10秒ごとに自動更新」をオンにし、「投影モード」でスクリーンに映す
3. 全員終わったら、相手別の協力率を見ながら議論
4. 「参加者名簿のCSV」で参加点をつける

## ゲームの仕様

- **ルールの導入**：2つの取調室を3Dで見せ、4通りの結果を「刑期ブロック」が積み上がる演出で体感させたあと、理解度チェック（1問）を行います
- **本番**：7人の相棒と各1回。**順番は学生ごとにランダム**。相棒は監視モニター越しに映り、全員が同じ内容（「2人とも黙っていれば1年で済む。黙っていよう」）をそれぞれの口調で言います
- **相手の選択**：どのキャラクターも同じ確率（初期値50%）でランダムに黙秘／自白。プレイ中は一切見せず、全員分が終わったあとに「判決」としてまとめて開示します
  - 最後まで見せたくない場合は `config.js` の `REVEAL` を `'none'` に（または URL に `?reveal=none`）
- **ボタンの左右**（黙秘／自白）は学生ごとにランダム
- 刑期：両者黙秘 1年ずつ／自分だけ自白 0年・相手10年／両者自白 5年ずつ（`config.js` の `PAYOFF` で変更可）
- 送信は最後にまとめて1回。失敗しても自動で再試行し、次にページを開いたときにも再送します。学生は「自分の記録をCSVで保存」でも控えを取れます

## 記録される列（1選択＝1行）

| 列 | 内容 |
|---|---|
| student_id | 学籍番号（半角大文字に正規化） |
| session_id / attempt | 1回のプレイのID／その端末でその学籍番号が何回目のプレイか |
| trial | 何番目に出てきた相手か（1〜7） |
| character_id / character_name | 相手（yakuza, woman, alien, robot, shiba, computer, child） |
| choice / cooperate | silent（黙秘）=1 ／ confess（自白）=0 |
| rt_ms / rt_first_ms | 選択肢が出てから「これで決める」まで／最初にどちらかを押すまでのミリ秒 |
| changed_mind / viewed_table | 決定前に選び直した回数／刑期の表を開いた回数 |
| partner_choice, my_years, partner_years | 相手の（ランダムな）選択と、その結果の刑期 |
| comp_answer / comp_correct | 理解度チェックの回答と正誤 |
| button_order | 左に出たボタン（silent_left / confess_left） |
| device / screen / user_agent | pc / smartphone / tablet、画面サイズ、ブラウザ |
| started_at / trial_at / received_at | 開始時刻／選択時刻（学生端末）／受信時刻（サーバ） |

先生用画面の「1人＝1行のCSV」には、相手ごとの協力（coop_◯◯）・考えた時間（rt_◯◯）・提示順（order_◯◯）が横に並びます。

## 注意

- 先生用ページ自体は誰でも開けますが、データは合言葉がないと読めません
- `Code.gs` を書き換えたときは **デプロイ → デプロイを管理 → ✏ 編集 → バージョン：新バージョン → デプロイ** で更新してください（URLは変わりません）
- 授業ごとにデータを分けたい場合は、先生用画面の「日付」で絞り込むか、スプレッドシートの行を別シートに移してください
- キャラクターはすべてプリミティブ形状で組んだオリジナル造形です
